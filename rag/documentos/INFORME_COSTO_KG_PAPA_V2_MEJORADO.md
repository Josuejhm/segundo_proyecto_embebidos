#### 1.2.3 CÁLCULO DEL COSTO POR KILOGRAMO

**COSTO BRUTO**:
```
Costo bruto/kg = Costo Total ÷ Kg Cosechados
                = S/ 2.751,00 ÷ 2.500 kg
                = S/ 1,10 por kilogramo
```

**COSTO LIMPIO** (asumiendo 10% merma post-cosecha):
```
Costo limpio/kg = Costo bruto ÷ (1 - merma)
                 = S/ 1,10 ÷ 0,90
                 = S/ 1,222 por kilogramo aprovechable
```

#### 1.2.4 ANÁLISIS DE VIABILIDAD

**DATO CRÍTICO**: Precio de venta en mercado = **S/ 1,00/kg**

**CÁLCULO DE MARGEN**:

| Métrica | Fórmula | Resultado | Interpretación |
|---|---|---|---|
| **Margen Unitario** | 1,00 - 1,10 | **-S/ 0,10/kg** | PÉRDIDA |
| **Margen Total** | (1,00 × 2.500) - 2.751 | **-S/ 251,00** | PÉRDIDA TOTAL |
| **Margen %** | (1,00 - 1,10) / 1,00 × 100 | **-10%** | 10% PÉRDIDA |

**PUNTO DE EQUILIBRIO**:

Asumiendo costos fijos S/ 1.500 (alquiler, depreciación):
- Costo variable unitario: (2.751 - 1.500) / 2.500 = S/ 0,50/kg
- Margen contribución: 1,00 - 0,50 = S/ 0,50/kg
- Punto equilibrio: 1.500 / 0,50 = **3.000 kg**

**Conclusión**: Necesita producir 3.000 kg pero solo cosecha 2.500 kg → NEGOCIO NO VIABLE.

#### 1.2.5 NECESIDAD DE PRECIO MÍNIMO

**Precio mínimo sin pérdida** (0% merma):
```
= S/ 2.751,00 ÷ 2.500 kg = S/ 1,10/kg
```

**Precio mínimo recomendado** (+10% margen, con 10% merma):
```
= S/ 2.751,00 ÷ (2.500 × 0,90)
= S/ 2.751,00 ÷ 2.250 kg
= S/ 1,223/kg
```

**BRECHA**: Vende a S/ 1,00 pero necesita S/ 1,223 = **DÉFICIT DE 18,3%**

## 2. CONCEPTOS FUNDAMENTALES APLICADOS A AMBOS ESTUDIOS

### 2.1 RELACIÓN COSTO-RENDIMIENTO

**Patrón Observado**:

| Contexto | Costo/kg | Rendimiento | Viable |
|---|---|---|---|
| **Ecuador Grande** | USD 0,164 | 34,09 Tm/ha | ✓ SÍ |

| **Ecuador Pequeño** | USD 0,177 | 26,21 Tm/ha | MARGINAL |
| **Perú Nativa** | S/ 1,10 | 10 Tm/ha (estimado) | ✗ NO |

**Fórmula Universal**:
```
Costo/kg inversamente proporcional a Rendimiento/ha
Costo/kg = (Costo Total/ha) ÷ (Rendimiento kg/ha)
```

### 2.2 FACTORES CRÍTICOS DIFERENCIADORES

#### Ecuador (Carchi - Tecnificado):
1. **Semilla certificada** vs tradicional (+30% rendimiento)
2. **Densidad de siembra**: Grande usa 50 qq/ha vs Pequeño 25 qq/ha
3. **Control fitosanitario**: Necesario por monocultivo (44% del mantenimiento)
4. **Resultado**: Economía de escala clara

#### Perú (Pumapaqcha - Nativa):
1. **Semilla de cosecha anterior** (sin certificación)
2. **Sistemas asociados** (no monocultivo, menor presión de plagas)
3. **Bajo rendimiento intrínseco** (~10 Tm/ha, vs 26-34 nacional)
4. **Resultado**: Margen negativo inevitable al precio de mercado

### 2.3 CÁLCULO DE COSTO LIMPIO - MÉTODO INTEGRADO

**Fórmula Cusco (Perú)**:
```
Costo Limpio = Costo Bruto ÷ (1 - % Merma)

Ejemplo:
Costo Bruto = S/ 1,10/kg
Merma = 10% (lavado y clasificación)
Costo Limpio = 1,10 ÷ 0,90 = S/ 1,222/kg

Incremento Real = 11,1% por merma
```

**Aplicación Carchi (Ecuador)**:
Si pequeño productor lava/clasifica papa:
```
Costo bruto = USD 0,177/kg
Merma típica = 15% (mayor daño post-cosecha)
Costo limpio = 0,177 ÷ 0,85 = USD 0,208/kg

Incremento = 17,5% (más alto porque rendimiento más frágil)
```

## 4. FÓRMULAS ESENCIALES CON EJEMPLOS REALES

### 4.1 Costo por Kilogramo (Ecuador - Carchi Grande)

```
FÓRMULA:
Costo/kg = Costo Total/ha ÷ Kg Cosechados

DATOS REALES:
Costo Total = USD 5.584,53/ha
Rendimiento = 34,09 Tm/ha = 34.090 kg/ha
Costo/kg = 5.584,53 ÷ 34.090 = USD 0,164/kg

VERIFICACIÓN:
34.090 kg × USD 0,164 = USD 5.582,76 ✓ (aprox USD 5.585)
```

### 4.2 Costo Limpio (Perú - Cusco Nativa)

```
FÓRMULA:
Costo Limpio = Costo Bruto ÷ (1 - % Merma)

DATOS REALES:
Costo Bruto = S/ 1,10/kg
Merma = 10% (descartes post-cosecha)
Costo Limpio = 1,10 ÷ (1 - 0,10)
             = 1,10 ÷ 0,90
             = S/ 1,222/kg

IMPLICACIÓN:
Por cada kg de papa limpia, costo real es S/ 1,222
Si vende a S/ 1,00 → PIERDE S/ 0,222/kg
```

### 4.3 Punto de Equilibrio (Perú - Cusco)

```
FÓRMULA:
PE = Costos Fijos ÷ (Precio - Costo Variable Unitario)

DATOS REALES (Estimado):
Costo Fijo = S/ 1.500 (asignación de alquiler, depreciación)
Costo Variable Total = S/ 1.251
Costo Variable Unitario = 1.251 ÷ 2.500 = S/ 0,50/kg
Precio Venta = S/ 1,00/kg

PE = 1.500 ÷ (1,00 - 0,50)
   = 1.500 ÷ 0,50
   = 3.000 kg

INTERPRETACIÓN:
- Debe producir/vender 3.000 kg para recuperar costos fijos
- Actualmente produce solo 2.500 kg
- Déficit: 500 kg (16,7% insuficiencia)
- CONCLUSIÓN: NEGOCIO INVIABLE a precio actual
```

### 4.4 Impacto de Intermediarios (Ecuador)

```
FÓRMULA:
Precio Final = Precio Productor × (1 + % Intermediario)

DATOS REALES:
Precio Productor = USD 0,15/kg (Carchi)
% Incremento Intermediario = 42,01%
Precio Consumidor Final = 0,15 × (1 + 0,4201)
                        = 0,15 × 1,4201
                        = USD 0,213/kg

MARGEN PERDIDO POR PRODUCTOR:
(0,213 - 0,15) ÷ 0,213 = 29,6% del valor final

ESCALA (1 Tm):
1.000 kg × USD 0,063 margen perdido = USD 63/Tm
En Carchi: 7.241 ha × 26+ Tm/ha = ~188.000 Tm/año
Valor perdido: USD 11,8 millones anuales (estimado)
```

```
Producción = 34,09 Tm/ha × 50 ha = 1.704,5 Tm = 1.704.500 kg
Costo/kg = 279.226,50 ÷ 1.704.500 = USD 0,164/kg

Margen unitario = 0,20 - 0,164 = USD 0,036/kg
Margen total = (0,20 × 1.704.500) - 279.226,50 = USD 61.673,50
Margen % = +18% (GANANCIA)

ESCALA TOTAL:
Ganancia anual = USD 61.673,50
Rentabilidad = 61.673 ÷ 279.227 = 22,1%

VIABILIDAD: EXCELENTE
- Vende directo a procesadores (Quito)
- Reduce intermediarios (solo 1,25% transporte)
- Economía de escala compensa inversión en certificación
```

## 7. ERRORES COMUNES A EVITAR

### Error 1: Omitir Mano de Obra Familiar

**Perú Pumapaqcha**: Se incluyó valor completo de jornales
- 12 jornales preparación × S/ 30 = S/ 360

**Ecuador Carchi**: También incluye mano obra completa
- Pequeño: 16,37% del costo = manojo de jornales

**Impacto si omite**: Costo real es 30-50% más alto

### Error 2: No Considerar Merma Poscosecha

**INCORRECTO**:
```
Costo/kg = 2.751 ÷ 2.500 = S/ 1,10 (fin de cálculo)
```

**CORRECTO**:
```
Merma lavado: 10%
Kg vendibles: 2.500 × 0,90 = 2.250 kg
Costo limpio: 2.751 ÷ 2.250 = S/ 1,222/kg
```

**Diferencia**: 11% más costoso (S/ 0,122/kg)

### Error 3: Ignorar Costo de Oportunidad del Terreno

**INCORRECTO**:
```
"Tengo terreno propio, no pago alquiler"
→ Costo omitido
```

**CORRECTO**:
```
Alquiler mercado Carchi: USD 500-700/ha/año
Ciclo 4 meses: USD 167-233 por ciclo
Incluir en costo total
```

**Impacto**: Rentabilidad real 15-20% menor

### Error 4: Confundir Precio Mercado con Margen

**PERÚ - ERROR FRECUENTE**:
```
"Vendo a S/ 1,00 y la papa cuesta S/ 0,90"
(Sin incluir todos los costos)
```

**REALIDAD SIVINCHA**:
```
Costo TOTAL (all-in) = S/ 1,10/kg
Precio mercado = S/ 1,00/kg
Margen = -10% (PÉRDIDA, no ganancia)
```

## 9. CONCLUSIONES INTEGRADAS

### 9.1 Hallazgos Principales

1. **Rendimiento es CRÍTICO**:
   - Ecuador grande (34 Tm/ha): Viable, USD 0,164/kg
   - Perú nativa (10 Tm/ha): No viable, S/ 1,10/kg

2. **Economía de escala importa**:
   - Pequeño Ecuador: USD 0,177/kg (8% más que grande)
   - Insumos y costos indirectos no escalan linealmente

3. **Intermediarios drenan 42%** (Ecuador):
   - Productor recibe USD 0,15/kg
   - Consumidor paga USD 0,213/kg
   - Brecha: USD 0,063/kg en manos ajenas

4. **Margen es negativo en Perú nativa**:
   - Costo real: S/ 1,222/kg
   - Precio: S/ 1,00/kg
   - Déficit: -18,3%

### 9.2 Recomendación Principal para Agente IA

**Cuando usuario pregunte "¿Cuál es mi costo por kilo?", SIEMPRE:**

1. Solicite ubicación exacta (país, provincia, productor)
2. Use tabla de referencia (Ecuador Carchi, Perú Cusco, etc.)
3. Verifique si incluye TODOS los costos (mano obra familiar, merma, costos indirectos)
4. Calcule costo limpio (con merma típica)
5. Compare con precio de mercado LOCAL
6. Indique si es VIABLE o NO
7. Sugiera mejoras específicas por contexto

**NO GENERALICE**: Ecuador ≠ Perú; pequeño ≠ grande; nativa ≠ certificada
